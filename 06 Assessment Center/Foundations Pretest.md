# Foundations Pretest

Select the best answer. Do not use notes. Record confidence as high/medium/low; a confident miss is a priority gap.

## Questions

1. A model is best described as: A) the whole product B) a learned computational component C) any automation D) the user interface.
2. RAG normally changes: A) base parameters B) inference-time context C) tokenizer vocabulary D) source ownership.
3. A high-accuracy rare-event detector can still be poor because: A) accuracy is always invalid B) base rates and error costs matter C) ML cannot detect rare events D) precision equals recall.
4. Calibration means: A) lowest latency B) predicted probabilities align with observed frequencies C) labels are balanced D) the model explains itself.
5. Which is leakage? A) time-based test split B) feature produced after the target decision C) held-out data D) missing values.
6. A clean dataset may be unfit when: A) it is CSV B) it lacks deployment coverage C) it has documentation D) it is encrypted.
7. Overfitting is: A) inability to fit training data B) strong transfer C) sample-specific learning that fails to generalize D) calibration.
8. A decision threshold primarily encodes: A) font choice B) error/capacity tradeoffs C) training hardware D) copyright.
9. Backpropagation calculates: A) gradients B) labels C) access rights D) retrieval ranks.
10. Quantization primarily changes: A) numerical precision B) legal rights C) source authority D) label ontology.
11. A token is: A) always a word B) a tokenizer-defined unit C) a database row D) a confidence score.
12. A longer context window guarantees: A) perfect recall B) lower cost C) neither; behavior must be evaluated D) copyrightability.
13. Grounding means: A) changing temperature B) tying output to supplied evidence/tool data C) offline training D) adding a persona.
14. A valid JSON response proves: A) semantic truth B) structural conformance only C) authorization D) safety.
15. Indirect prompt injection arrives through: A) model weights only B) content the system processes C) a database index only D) a compiler.
16. Least privilege means: A) no users B) minimum needed permissions C) maximum context D) shortest prompt.
17. Hybrid retrieval combines: A) two labels B) lexical and dense/other signals C) training and inference D) two users.
18. Authority ranking is separate from relevance because: A) relevant sources may be obsolete/unofficial B) vectors are illegal C) metadata is unnecessary D) all sources agree.
19. An agent differs from a fixed workflow when: A) it uses JSON B) a model selects/sequences actions from state C) it has a UI D) it runs in cloud.
20. A safe agent evaluation includes: A) final wording only B) intermediate actions and side effects C) token count only D) user likes only.
21. Slice analysis asks: A) which subsets hide different behavior B) which vendor is cheapest C) which prompt is longest D) which logo users prefer.
22. A red-team finding proves: A) population prevalence B) a failure was possible under found conditions C) every user is affected D) the model is unlawful.
23. Shadow deployment: A) controls user outcomes B) observes duplicated traffic without controlling results C) deletes logs D) has no model.
24. An SLO is: A) measured indicator B) target for an indicator over time C) contract always D) source license.
25. Security asks primarily about: A) authorized confidentiality/integrity/availability/control B) aesthetics C) adoption D) authorship.
26. Meaningful human review requires: A) a human name B) time, evidence, competence, authority, and alternative C) a checkbox D) model agreement.
27. NIST AI RMF functions are: A) build/buy/sell B) Govern/Map/Measure/Manage C) plan/code/test D) collect/train/deploy.
28. A prototype establishes: A) production readiness B) learning under its tested conditions C) broad legal compliance D) guaranteed ROI.
29. A strong adoption metric connects use to: A) acceptable task and operational outcomes B) login volume only C) model size D) press coverage.
30. The best first architecture is generally: A) most autonomous B) least complex approach that meets evidence and constraints C) largest model D) newest vendor.
