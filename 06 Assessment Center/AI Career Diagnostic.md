# AI Career Diagnostic

Use three signals: work preference, evidence preference, and current foundation. A result suggests profiles to investigate; it does not prescribe your career.

## Part A — recurring work preference

For each row, choose **A or B** even if both appeal.

| # | A | B |
|---:|---|---|
| 1 | discover a new method | apply a known method to a user problem |
| 2 | write and debug code | map and improve a business workflow |
| 3 | optimize latency/reliability | design the human interaction |
| 4 | attack and break a system | document and govern a system |
| 5 | analyze experimental data | persuade and enable a customer |
| 6 | structure knowledge/data | coordinate people and delivery |
| 7 | make media/content | validate evidence and controls |
| 8 | decide what product to build | decide how to implement architecture |
| 9 | tune models/algorithms | tune prompts/context/workflows |
| 10 | work on one deep technical problem | work across functions and ambiguity |
| 11 | own infrastructure | own adoption/outcomes |
| 12 | create labels/feedback quality | create policy/standards |

### Interpret Part A

Do not total every A together. Note the **verbs** you repeatedly chose:

- discover/experiment → research and applied science;
- code/build/tune → engineering;
- optimize/operate → platform, MLOps, inference, hardware;
- attack/protect → security and red team;
- validate/evidence → evaluation, risk, audit, assurance;
- decide/prioritize/coordinate → product, program, strategy;
- design/research interaction → UX, conversation, content;
- persuade/enable/negotiate → solutions, enterprise sales, product marketing, partnerships, success, support, DevRel, training;
- create → creative media;
- structure/label → data, knowledge, human-feedback operations;
- govern/policy → governance, compliance, privacy, policy, ethics;
- investigate/escalate → trust-and-safety operations or technical support/user operations;
- set enterprise direction → executive AI leadership, reached through senior feeder roles rather than as a first job.

Use [[Choose Your AI Career]] for matching roles.

- [ ] transformed workflow and adoption

Your first-ranked evidence should match the primary role. Use the other two as differentiating edges.

## Part C — foundation check

Answer yes only if you can explain and apply it without searching.

- [ ] I can distinguish a model from a complete AI system.
- [ ] I can explain training, inference, prompting, retrieval, and fine-tuning.
- [ ] I can interpret precision, recall, calibration, and uncertainty.
- [ ] I can identify leakage, shift, and weak data provenance.
- [ ] I can trace a generative request through context, retrieval, tools, and validation.
- [ ] I can explain prompt injection and least privilege.
- [ ] I can design representative evaluation cases and slice results.
- [ ] I can connect an SLO, rollback, and incident response to an AI service.
- [ ] I can distinguish security, privacy, safety, fairness, and accessibility.
- [ ] I can connect adoption to acceptable task success and business/public value.
