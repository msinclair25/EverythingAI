# Project Bank

Adapt an idea to your role and an authorized domain. Role profiles contain more specific projects.

## Beginner

| Idea | Show |
|---|---|
| Compare three model/tool approaches on 30 representative tasks | rubric design, error taxonomy, cost/latency, honest conclusion |
| Build a prompt/context style guide for one workflow | versioning, examples, refusal and uncertainty states |
| Audit a public AI product experience | UX states, accessibility, trust calibration, recovery |
| Create a small annotated dataset and guideline | construct definition, boundary cases, agreement, limitations |
| Build a U.S. AI policy/source tracker | source authority, effective dates, update workflow |
| Design a creative campaign concept with production record | human contribution, input rights, provenance, quality review |
| Map one AI product's buyer journey and support journey | audience, value claim, discovery questions, objections, escalation boundaries |
